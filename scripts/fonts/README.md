# Preview font

`inconsolata_bold.ttf` is the unmodified Inconsolata Bold distributed in the
local Air Manager 4.2 installation (copyright 2006 The Inconsolata Project
Authors). It is included under the adjacent SIL Open Font License so the
artwork generator can use the same glyphs without an Air Manager installation.

The live instruments use Air Manager's built-in `inconsolata_bold.ttf`.
