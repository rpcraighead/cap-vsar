Mission Base, Ground Radio & SAR Planning

A comprehensive search-and-rescue mission does not begin or end in the cockpit. CAP V-SAR delivers an integrated ground command ecosystem—from the Mission Radio Operator (MRO) touch-friendly console to the N499CP Automated SAR Flight Planner and Post-Sortie Telemetry Debrief.

Radio Communications Hub

MRO Base Radio Console

Operating at http://ms01:8700/radio, the Virtual Base Radio console provides Mission Radio Operators with a full-fidelity hardware emulation designed specifically for laptops, desktops, and touch-screen tablets in the field command trailer.

  • ✓ Dual Radio Emulation: Run both the Motorola APX 6500 and Icom IC-A120 concurrently in a side-by-side or stacked rack configuration (/radio?mode=dual).
  • ✓ Web Audio Acoustic Engine: Authentic 3-tone P25 digital talkgroup permit chirp, aviation AM side-tone, mechanical relay clicks, and squelch tail gate.
  • ✓ Instant Touch & Keyboard PTT: Tactile Push-To-Talk button with spacebar hotkey binding for hands-on-headset dispatching.
  • ✓ Zero-Client Deployment: Pure browser client built in HTML5/CSS/JavaScript with zero installation required on operator tablets.
VHF-FM Tactical Communications

Motorola APX 6500 VHF-FM Console

The primary land mobile radio for CAP incident command and wing-wide tactical communications. Emulates authentic digital and analog channel operations.

  • ✓ Zone/Channel Management: Zone 1 (Command/Air-to-Ground), Zone 2 (Tactical Primary), and Zone 3 (Inter-agency interoperability).
  • ✓ P25 Digital Audio: Simulated digital audio packetization with distinctive 3-tone permit beep upon keying up.
  • ✓ Volume & Squelch Knobs: Interactive continuous rotary encoders with visual tick markers and decibel readouts.
VHF-AM Aviation Communications

Icom IC-A120 Airband Transceiver

Dedicated VHF-AM transceiver for monitoring aircraft airborne frequencies, flight release confirmations, and emergency guard channels.

  • ✓ Aviation Frequencies: 118.000 to 136.975 MHz with 8.33 kHz / 25 kHz channel spacing simulation.
  • ✓ Preset Emergency Channels: Instant 1-touch jump to 121.500 Guard, 122.900 SAR Secondary, and 123.100 SAR Primary.
  • ✓ Backlit Segment LCD: Authentic high-contrast amber dot-matrix display with scanning indicators.

Pre-Sortie Navigation

N499CP Automated SAR Flight Planner

Hosted at http://ms01:8090, the dedicated web-based flight planner combines live georeferenced FAA VFR sectional charts with mathematical SAR pattern generation, eliminating manual plotting errors.

  • ✓ FAA VFR Sectionals: High-resolution georeferenced chart underlays (Seattle, Klamath Falls, Great Falls, and CONUS).
  • ✓ Standard SAR Patterns: Expanding Square, Creeping Line, and Parallel Track calculated using true WGS-84 geodetic algorithms.
  • ✓ Direct FMS Export: Generate native X-Plane .fms flight plans in 1-click for immediate upload to the cockpit Garmin G1000.
  • ✓ Fuel & Burn Profiling: Pre-computes climb, cruise, and loiter fuel burn for the Lycoming IO-540-AB1A5 engine.
Pattern Type: SS

Expanding Square (SS)

Utilized when datum location is known with high confidence (e.g. reported distress coordinates or last radar hit). All turns are 90° right:

Leg 1: 1S • Leg 2: 1S
Leg 3: 2S • Leg 4: 2S
Leg 5: 3S • Leg 6: 3S ...

Configurable track spacing S (0.5 to 2.0 NM) matching search altitude and target visibility.

Pattern Type: CS

Creeping Line (CS)

Designed for searching along an axis of travel (highway, valley, river, or proposed aircraft flight plan corridor).

Search Legs: Perpendicular
Advance Legs: Along corridor
Leg Width: 2L • Advance: 1S

Sweeps laterally across the high-probability axis while advancing systematically along track.

Pattern Type: PS

Parallel Track (PS)

Employed for large, uniform rectangular search areas where target position uncertainty is evenly distributed.

Major Axis: Track Length L
Reversals: 180° teardrop/button
Spacing: Constant S

Ensures 100% geometric coverage with uniform Probability of Detection (POD) across the entire grid.

Command Situational Awareness

Mission Base Tactical Map

The Incident Commander and Operations Section Chief monitor the sortie live at http://ms01:8700/base. The map renders real-time telemetry from the aircraft via UDP data streams.

  • ✓ Live Aircraft Position Vector: Continuous display of N499CP's true position, altitude MSL/AGL, ground speed, and heading vector.
  • ✓ Real-Time Bearing Cuts: Whenever the Mission Observer reports a DF heading, bearing lines project dynamically across the chart to identify triangulation intersections.
  • ✓ Fog of War Control: Target truth location is obscured for trainees but instantly toggleable for instructors with hotkey overrides.
  • ✓ CAP Standard Grids: Instant 15-minute standard sectional grid overlay with 4-quadrant (A, B, C, D) sub-grid labeling.
Objective Assessment

Sortie Debrief & Telemetry Scoring

Replace subjective debrief opinions with mathematical precision. The debrief console records the entire flight trajectory and performs automated mathematical validation:

  • ✓ Timeline Replay Slider: Scrub forward and backward across the flight in 1-second increments with synchronized altitude, airspeed, and radio callouts.
  • ✓ Closest Point of Approach (CPA): Exact calculation of closest fly-by distance and time relative to the target ELT beacon.
  • ✓ Search Track Efficiency Score: Quantitative score comparing flown track against optimal pattern geometry and corridor boundaries.
  • ✓ Signal Acquisition Milestone Log: Records first RF reception, DF lock, aural confirmation, and overhead beacon passage.
