RF Propagation Physics & System Architecture

Unlike arcade simulators that use simplified proximity spheres, CAP V-SAR implements aerospace-grade 3D electromagnetic propagation models. We simulate true radio line-of-sight refraction, Friis path loss, terrain shadowing, antenna nulls, and authentic 406 MHz COSPAS-SARSAT digital telemetry.

Electromagnetic Simulation

3D Radio Wave Propagation Engine

Implemented in the high-performance Python/C++ plugin layer (PI_capvsar_df.py), the RF engine evaluates propagation vectors at 20 Hz between the aircraft's multi-element DF antenna array and active ground or distress beacons.

4/3 Effective Earth Radius & Radio Horizon
d_{horizon} \approx 1.23 \left(\sqrt{h_{rx}} + \sqrt{h_{tx}}\right)

Atmospheric refractivity bends VHF/UHF radio waves downward slightly, extending the radio horizon beyond the optical horizon by approximately 15%.

dhorizon: Maximum theoretical line-of-sight range in nautical miles (NM)
hrx: Aircraft receiver antenna altitude in feet Above Ground Level (ft AGL)
htx: Ground emergency beacon transmitter antenna height in feet AGL
Free Space Path Loss & Received Signal Power
P_{rx} = P_{tx} + G_{tx} + G_{rx} - 20\log_{10}(d) - 20\log_{10}(f) - 32.44 - L_{shadow}

Calculates received signal power in dBm across slant range distance, taking into account antenna gains and topographical occlusion.

Prx: Received signal power at DF receiver front-end (dBm)
Ptx: Transmitter output power (e.g., +20 dBm for 100 mW 121.5 MHz; +37 dBm for 5W 406 MHz)
d, f: Slant range distance in kilometers (km) and carrier frequency in megahertz (MHz)
Lshadow: Knife-edge diffraction attenuation behind terrain ridges (up to 40 dB)
Null Overhead

Antenna Cone of Confusion

Vertical monopole and dipole antennas exhibit an electromagnetic null directly along their vertical axis ($Z$-axis). When an aircraft flies directly over a beacon:

  • • Signal strength plummets 30+ dB within a 60° inverted cone.
  • • The DF needle swings erratically, confirming station passage.
Airframe Masking

Wing & Fuselage Shadowing

When an aircraft enters a 30° to 45° steep bank during homing turns, the aluminum wings and fuselage partially occlude the line of sight between the antenna and the signal source:

  • • Produces authentic bearing jitter and temporary signal attenuation.
  • • Trains aircrews to maintain level wings when taking bearing cuts.
Terrain Occlusion

Topographic Shadowing

Digital elevation ray-tracing verifies whether a mountain ridge or canyon wall interrupts the direct line-of-sight vector between transmitter and receiver:

  • • Simulates total RF cutoffs behind mountain ridges in SAR areas.
  • • Requires pilots to climb to altitude to re-acquire radio line of sight.

Distress Protocol Emulation

406.025 MHz COSPAS-SARSAT Digital Protocol

Modern Emergency Locator Transmitters (ELTs) and Personal Locator Beacons (PLBs) broadcast digital data packets on 406.025 MHz in addition to the traditional 121.5 MHz analog swept tone. CAP V-SAR replicates the complete digital pulse cadence and data decoding.

Protocol Parameter Specification (C/S T.001 Standard) CAP V-SAR Implementation Behavior
Carrier Frequency 406.025 MHz ± 2 kHz Simulated Doppler shift based on aircraft relative velocity ($\Delta f = f_0 \frac{v_{rel}}{c}$).
Burst Repetition Rate 50.0 ± 2.5 seconds (randomized) Accurate pseudo-random transmission interval prevents synchronized collision between multiple beacons.
Burst Transmission Duration 520 milliseconds (long format) Triggers instantaneous 520 ms DF strobe flag in datarefs and triggers audio pulse.
Modulation & Bit Rate Bi-phase L (Manchester) at 400 bps 112 or 144 bit digital telegram containing hex ID, country code, and coordinate offsets.
15-Hex Identity Synthesis e.g. 38CB4C99AB770F9 Decoded by the RHOTHETA RT-600 dot-matrix display and base station decoder in real-time.
Indicator Timehold Decay 30 seconds retention on display Becker 517 flashing lock holdover; needle slowly returns to search sweep if no burst arrives within 55s.

X-Plane Dataref & Variable Contracts

The simulation bridge communicates with Air Manager instruments and external applications through a published set of high-speed custom datarefs.

Dataref Identifier Type & Units Update Rate Description & Physical Meaning
cap/df/bearing_rel_deg Float (deg: -180 to +180) 20 Hz Relative bearing from aircraft nose to active transmitter (0 = dead ahead, +90 = 3 o'clock).
cap/df/bearing_mag_deg Float (deg: 000 to 359) 20 Hz Absolute magnetic bearing from aircraft to transmitter, compensated for current magnetic variation.
cap/df/signal_strength_pct Float (percent: 0 to 100) 20 Hz Smoothed receiver signal quality indicator driven by Friis equation and link budget.
cap/df/frequency_hz Int (Hertz: e.g. 121500000) On Change Currently tuned homing frequency (121.5 MHz, 243.0 MHz, 406.025 MHz).
cap/df/burst_active Int (Boolean: 0 or 1) Instantaneous Set to 1 during the active 520 ms 406 MHz COSPAS-SARSAT RF burst; 0 during quiet period.
cap/df/cone_of_confusion Int (Boolean: 0 or 1) 20 Hz Active when aircraft is inside the 60-degree inverted null cone directly overhead the beacon.
cap/df/terrain_shadowed Int (Boolean: 0 or 1) 20 Hz Active when topographical terrain blocks the direct radio line of sight.
cap_fm_freq_active Float (MHz: e.g. 148.150) On Change Active tactical channel tuned on the Technisonic TDFM-136B airborne VHF-FM radio.
cap_fm_ptt Int (Boolean: 0 or 1) Instantaneous Tactical radio Push-To-Talk state routed from yoke or observer panel button.
Avionics Rendering

Air Manager 4.2 Lua Vector Architecture

To achieve photorealistic instrument displays without texture blurring or frame drops, the Becker SAR-DF 517 and RHOTHETA RT-600 instruments employ double-buffered hardware vector graphics:

lua/becker_517_render.lua — Hardware Redraw Implementation 
-- Becker SAR-DF 517 Vector Redraw Loop (Air Manager 4.2+)
local canvas_needle = canvas_add(0, 0, 512, 512)

function render_df_needle(rel_bearing, sig_strength, is_burst, in_cone)
    canvas_draw(canvas_needle, function()
        _style(CLEAR)
        
        -- If signal is below squelch threshold or in overhead cone, simulate jitter
        if sig_strength < 5.0 or in_cone == 1 then
            local jitter = math.random(-25, 25)
            rel_bearing = rel_bearing + jitter
        end

        -- Draw high-contrast LCD circular bearing scale
        _circle(256, 256, 180)
        _color(0.12, 0.15, 0.18, 1.0)
        _stroke(2)

        -- Render primary indicator pointer with antialiasing
        local rad = math.rad(rel_bearing - 90)
        local x_tip = 256 + 170 * math.cos(rad)
        local y_tip = 256 + 170 * math.sin(rad)

        _line(256, 256, x_tip, y_tip)
        _color(0.95, 0.20, 0.25, 1.0) -- Soft crimson indicator
        _stroke(4)
    end)
end

-- Subscribe to high-speed X-Plane datarefs
xpl_dataref_subscribe("cap/df/bearing_rel_deg", "FLOAT",
                      "cap/df/signal_strength_pct", "FLOAT",
                      "cap/df/burst_active", "INT",
                      "cap/df/cone_of_confusion", "INT",
                      render_df_needle)
Deployment Infrastructure

Microservice Container Architecture

CAP V-SAR backend components are packaged as isolated, lightweight Docker containers orchestrated via docker-compose.prod.yml.

capvsar-exercise

Core simulation server managing exercise state, beacon truth coordinates, UDP telemetry listeners from X-Plane, and hosting the MRO Base Radio console and Debrief application.

capvsar-flightplanner

High-performance web mapping interface serving georeferenced FAA VFR sectional tiles, calculating WGS-84 search patterns, and compiling downloadable .fms files.

mumble-server

Sub-20ms latency tactical voice network connecting pilot headsets, observer stations, and ground radio operators with channel separation and radio PTT effects.
