# C182T package review (2026-10-11)

Scope: the Cessna 182T NAV III (CAP 487) aircraft package as built by
`scripts/build_c182t_package.py`, the documents behind it, and the AI pilot
code that is meant to fly it. Reviewed on `main` at c5267ab against the
installed package (`~/X-Plane 12/Aircraft/CAP/Cessna 182T NAV III`, built
2026-10-10 12:46 from 57663ec). Method: a parameter-level diff of the built ACF
against the Laminar C172SP G1000 it is derived from (190 lines differ; every
C172 value the builder leaves alone is therefore visible), checked against
the 182T NAV III information manual (P/N 182TPHBUS, SHA-256
`ba64adab…3fd2705c`, re-fetched for this review and matching the hash the
dimension master pins) and the EASA 182-series TCDS. Nothing in the package
was changed by this review. Findings are tracker cluster C18 (`A2-n`).

The related work product is on branch `feat/c182-ai-pilot-baseline`: the C172
AI pilot controllers parametrised by aircraft profile with a sourced C182T
record, plus search-pattern geometry and a pattern-flying controller
(`docs/C182T_AI_PILOT_PORT_2026-10-11.md` there).

## 2. Inaccuracies found

**A2-1 — Six cylinders, not four.** `acf/_num_cylinders` is still the C172's 4.
The IO-540 has six. X-Plane uses the count for the engine model's firing and
sound, and the G1000 lean-assist page shows per-cylinder EGT/CHT bars, so the
cockpit shows a four-cylinder engine. Fix: patch `acf/_num_cylinders 6` in
`ACF_PATCHES`. Effort S.

**A2-2 — The physics propeller is still the C172's 76-inch two-blade geometry
with a third blade added.** `_blad/0/_semilen_SEG 3.200` ft gives a 76.8-inch
disc; the 182T's is 79.0 in (TCDS, POH), so `_semilen_SEG` should be 3.2917 ft
(6 % less disc area as built). Blade chords (`_Croot 0.333`, `_Ctip 0.250` ft)
and the 10°/40° pitch range are the C172 two-blade's and unsourced for the
B3D36C431. The visual propeller was corrected to 79.0 in (`c182t_corrections`),
so the picture and the physics disagree. This is a live candidate for part of
the C1 cruise shortfall and should be corrected before the fuselage-Cd
experiment is flown, or the experiment will calibrate drag against the wrong
propeller. Fix: patch `_blad/0/_semilen_SEG 3.291667`; take blade angle limits
at the 30-in station from FAA TCDS 3A13 p.33 (the project already holds that
document) for `_min_pitch`/`_max_pitch`; leave chord unless a source appears.
Effort S for the radius, M for a sourced blade.

**A2-3 — Landing-gear physics is the C172's; the visual gear was moved to the
182T track.** `_gear/1,2/_gear_x ±1.600` ft with `_latE −57°` and a 3.0 ft leg
give an 8.2 ft contact track (the C172SP's 8 ft 4 in), while
`c182t_corrections.json` scales the mesh to the POH's 9 ft 0 in. The wheels are
drawn about 5 in outboard of where the aircraft actually stands on each side,
and the wheelbase (nose gear `_gear_z −0.60`, mains 4.60 plus `_lonE`) is the
C172's 65 in, not 66.5 in. Ground-handling effects are small; the visual
mismatch is not. Fix: set the gear lateral/longitudinal attach so the contact
points sit at 9 ft track and 66.5 in wheelbase (the dimension master already
carries both), re-run `measure_c182t.py`. Effort S–M.

**A2-4 — Full-throttle power is 7 % low and unexplained.** The C1 record shows
214 HP at 2400 RPM near sea level against 230 rated. Ambient pressure at 556 ft
explains about 2 %. Candidates are the propeller absorbing less than the
engine can give (A2-2), `_max_MP_limit 29.9`, and `_engine_friction_ratio`.
Not a defect to patch blind: fix A2-2, re-fly C1, then look. Effort M.

**A2-5 — Two identities on one aircraft.** The ACF tail number is `CAP 487`
and the builder's docstring argues, rightly, against painting a real
aircraft's registration on a different simulated type. Yet when the downloaded
CAP C172 artwork is present the build makes the N429CP paint the aircraft's
default texture and selection icon, with a note that the original author and
URL are unknown. The crew sees N429CP on the skin and CAP 487 on the G1000 and
in ATC. Fix: either repaint the registration block to CAP 487 in
`adapt_cap_livery.py` (the registration is a texture region the mapper
already locates) or make the generated `Civil Air Patrol (CAP 487)` livery
the default and keep N429CP as an optional named livery; update the README
line "approved N429CP paint as the default". Effort S.

**A2-6 — The package ships the wrong manuals.** `X-Plane_C172_Pilot_Operating_Manual.pdf`,
the G430/G530 manuals and the S-TEC autopilot manual are copied from the C172
folder. The 182T NAV III has a GFC 700 and no S-TEC; the C172 manual's speeds
are the ones this package must not be flown by. Fix: drop them in the builder
(the package has no X-Plane-side dependency on them) or replace with a one-page
`README` pointing at the project's own documents. Effort S.

**A2-7 — Checklist text contradicts the ACF.** `services/ai_pilot/c182t_checklists.py`
says "full 30 deg below 100 KIAS" and "20 deg below 120"; the 182T's full flap is
38° (ACF detent 3 and TCDS) and the POH wording is "20° – FULL below 100". Also
"RETRACT UP (ABOVE 70 KIAS)" is right but the normal-takeoff flap setting
(10° preferred) is not stated. Effort S.

**A2-8 — `acf/_Va_kts` is 0.** The G1000 does not display Va, but the AI
pilot envelope documents and any future stress check read the ACF. POH: 110
KIAS at 3100 lb. Effort S.

**A2-9 — The builder's hard-coded `/home/ron` paths.** `DEFAULT_SOURCE_DIR`,
`DEFAULT_TARGET_DIR` and the livery/icon defaults. Known, minor; it blocks
nobody today and is noted so it is not re-found. Effort S.

## 3. Improvement opportunities

**A2-10 — Pin the ACF to the sources with a test.** `ACF_PATCHES` and
`scripts/c182t_dimension_master.json` both carry 182T numbers and nothing
checks that they agree, which is how A2-1/A2-2 survived: the dimension master
knows the propeller is 79 in and the ACF does not. A test that reads the
built (or staged) ACF and asserts each sourced field against the JSON, and
that lists every `_engn/_prop/_blad/_gear` field left at its C172 value,
would make the next unpatched inheritance visible. Effort M.

**A2-11 — Calibration order.** Fix A2-2 (and A2-3 for the ground), re-fly
B1/C1 at 3,100 lb, then run the staged fuselage-Cd experiment. Flying the Cd
experiment first calibrates drag against the wrong propeller.

**A2-12 — Empty weight.** 1,924 lb is the POH sample aircraft (chosen as the
shared planner/simulator baseline, L-7a, which is the right call for
consistency). A real CAP 182T NAV III with mission equipment is heavier; if a
weight-and-balance sheet for a squadron 182 is available, both sides should
move to it together (`tests/test_loading_baseline.py` guards that).

**A2-13 — The AI pilot now has an aircraft profile layer** (branch
`feat/c182-ai-pilot-baseline`). The remaining C172-specific code is in the
runner scripts, `experiment.Scenario.aircraft_name`, and the taxi throttle
constants; the port document lists the order to close them.

**A2-14 — Document index.** Seven `docs/C182T_*.md` files plus the GPL plan,
the calibration doc and CHANGELOG entries describe the package. A short
`docs/C182T_INDEX.md` saying which document is authoritative for what
(dimensions → DIMENSION_MASTER; identity/licence → GPL_PLAN; flight model →
CALIBRATION; controllers → the port doc) would save the next reader the hour
this review spent.

## 4. Not reviewed

The converted exterior mesh and texture beyond what the CHANGELOG records;

deliberately, per the calibration doc); the FMOD sound set (still the C172's,
